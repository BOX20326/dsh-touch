# 摸摸 · dsh-touch

把 **PS5 手柄（DualSense）的触摸板**变成"触感"，投给 DSH 里的 AI 伴侣。
你摸手柄，她收到"被摸"；她也能反过来调手柄震动，摸回你。

> 灵感来自 B 站用户 **Duke__** 的「已成功摸到我家鱼」。
> 这是一个给 DeepSeek Harness（DSH）用的本地插件，和索尼官方无关。

---

## 功能

- **触摸板 → 触感**：摸、抚摸、揉（画圈）、挠（快速来回）、戳、双手、搭手（按住不动）
- **力气曲线**：不是一句"有点用力"，而是 `力气 34→61→22` 这样的形状（触摸板没有压力传感器，用速度估的）
- **扳机 = 捏**：L2/R2 是真实模拟量，捏多深就是多重；还能给扳机加**物理阻力**，不容易一下按到底
- **按键动作**：△摸头 ○抱抱 ×戳 □捏脸
- **灯条反馈**：每个动作一种颜色
- **她摸回来**：工具 `touch_back`（轻抚 / 摸头 / 点点 / 抱紧 / 心跳 / 挠挠，力度可调）
- **她感觉你**：工具 `touch_sense`（此刻手指在不在、压在哪、力气多大、有没有在捏）
- **回震窗口**：发完一条触感后本地静音几秒，让她的震动直接落在你摸着触摸板的手指上
- **热插拔**：拔线 4 秒自动松开，插回来 3 秒内自动接上
- **侧栏设置面板**：识别节奏、回震窗口、扳机阻力、手感开关，全在面板上调，改完 3 秒生效
- **热重载**：改逻辑层代码存盘 2 秒自动换新实例，不用重启 DSH

## 要求

- Windows（目前只在 Windows 上测过；macOS / Linux 未验证）
- DSH 0.2.x（自带 Node ≥ 22，插件用的运行时就是它）
- PS5 DualSense 手柄（USB 连接；Edge 版应该也行，未测）
- 不需要装驱动

DS4（PS4 手柄）和笔记本触摸板**还没做**，欢迎 PR。

## 安装

1. 把这个文件夹放到任意位置，例如 `C:\dsh-plugins\dsh-touch`。

2. 在 DSH 的 profile 里登记（一般是 `C:\Users\<你>\.dsh\profiles\desktop\package.json`）：

```json
{
  "dependencies": {
    "dsh-touch": "link:C:/dsh-plugins/dsh-touch"
  },
  "dsh": {
    "profile": {
      "bundles": [
        "... 其他 bundle ...",
        "dsh-touch"
      ]
    }
  }
}
```

> 注意：`link:` 后面用**正斜杠**，路径写你实际放的位置。

3. 在这个文件夹里装依赖（用 DSH 自带的那套 node/pnpm 也行，或者你自己的）：

```bash
pnpm install
# 或 npm install
```

4. 重启 DSH。

5. 侧栏会出现一个「摸摸」图标。点开是设置面板；
   第一次用先确认 `启用` 打开、`目标会话` 填成你的 AI 伴侣的会话 id，
   再把 `dryRun` 先开着试（只写日志不投递），确认没问题再关掉。

> 默认配置是**关着的**：`config.json` 里 `启用: false`。
> 第一次可以复制 `config.example.json` 成 `config.json` 再改。

## 怎么玩

| 你的动作 | 她收到的 |
| --- | --- |
| 手指慢慢划 | （触感·摸）他摸了摸你：力气 34→61→22，从左往右，0.9 秒。 |
| 长按慢慢摸 | （触感·摸）他慢慢摸你：力气 … |
| 画圈 | （触感·揉）他一圈一圈揉你：力气 … |
| 快速来回 | （触感·挠）他挠了挠你 |
| 点一下 | （触感·戳）他戳了你一下 |
| 两根手指 | （触感·双手）他两只手一起摸你 |
| 按住不动 | （触感·搭手）他把手放在你身上，没动，停了一会儿 |
| 捏 L2/R2 | （触感·捏）他捏住你：真压力 78/100，压了 0.3 秒，松开了 |
| △ / ○ / × / □ | （手柄）他伸手摸了摸你的头 / 他把你抱住了 / … |

她那边拿到两个工具：

- `touch_back(动作, 力度)`：让手柄震起来 = 她伸手摸你
- `touch_sense()`：感觉一下此刻的你

第一次收到触感时，消息末尾会附一句"可以用 touch_back 摸回来"（可在面板关掉）。

### 识别节奏（防刷屏）

- 一次连续触摸只发一条
- 手停 1.2 秒算一段结束；再停住不补发
- 一直在动：每 10 秒最多一段
- 两条消息之间最少隔 6 秒
- 这些都在面板 / `config.json` 的 `识别节奏` 里改

### 扳机阻力

用 DualSense 自适应扳机的官方 feedback 模式：按到 `起点` 之后开始顶手，`力度` 越大越硬。
默认 `起点 90 / 255`（约 35%）、`力度 130`。面板上可以直接调。

## 配置

面板改的全部落到 `config.json`（放在插件文件夹下）；也可以手改，3 秒内生效。

```jsonc
{
  "启用": false,             // 总开关
  "dryRun": true,            // true = 只写日志不投递
  "目标会话": "",            // DSH 会话 id（她的会话）
  "震动反馈": true,
  "灯条": true,
  "扳机": true,              // 扳机识别"捏"
  "按键动作": true,
  "提示回摸": true,
  "最小间隔毫秒": 6000,
  "回震窗口毫秒": 10000,
  "识别节奏": { "停顿毫秒": 1200, "最长段": 10000, "单帧动": 2.5 },
  "扳机阻力": { "启用": true, "起点": 90, "力度": 130 }
}
```

日志：`<DSH_HOME>/touch/touch.log`（Windows 默认 `C:\Users\<你>\.dsh\touch\touch.log`）。

## 原理（一页说完）

```
DualSense ──USB HID──▶ node-hid ──▶ hid.mjs（解析报告）
                                    ├─ 触摸点：[33..36] / [37..40]
                                    ├─ 扳机：byte5 / byte6
                                    └─ 灯条 / 震动 / 扳机效果：63 字节输出报告
                                        ▼
                                   core.mjs（状态机：连成动作 + 估力气 + 限流）
                                        ▼
                                   impl.mjs（投递给会话：agents.get(id).followup()）
                                        ▼
                                   她的会话 ──▶ 回一句 / 调 touch_back 震回来
```

- 触摸点/按钮/陀螺仪布局参考 Linux 内核 `drivers/hid/hid-playstation.c`
- 扳机阻力与灯条字节位置参考微软 GameInput 的 `companion/DualSense/DualSenseHelper.h`
- 扳机效果模式参考 [Nielk1 的 DualSense trigger effects gist](https://gist.github.com/Nielk1/6d54cc2c00d2201ccb8c2720ad7538db)

### 代码结构

```
index.js      入口（很薄）：注册工具、注册 /dsh-touch/* 路由、每 2 秒看文件签名做热重载
impl.mjs      逻辑（厚）：HID 打开/重连、状态机、投递、配置
core.mjs      识别：帧 → 动作 → 一句话（纯逻辑，可单测）
hid.mjs       报文解析 / 震动包 / 扳机效果（纯函数，可单测）
client.js     侧栏「摸摸」面板（React，走宿主路由）
test/offline.mjs  离线测试：不碰设备、不碰 DSH
```

为什么拆两层：DSH 的 ESM 模块缓存按 URL 走，入口把 `impl.mjs` 用"文件签名当 query"重新 import，
就能换出新实例——所以改逻辑层不用重启 DSH。

## 安全边界

- 只往**配置里指定的那一个会话**投递，不群发
- 不写 DSH 的 `.dsh/sessions/`、不写 `workspace.json`、不碰对方的档案
- 默认关闭；`dryRun` 只写日志
- 所有异常内部吃掉，不会让 DSH 崩

---

## 已知限制

- 只在 Windows + DSH 0.2.x + DualSense（USB）上实测过
- 触摸板没有压力传感器，"力气"是**用速度估的**；真压力只有扳机有
- 震动用的是"兼容振动"模式（两个马达），不是 DualSense 的高级触觉
- 笔记本触摸板 / DS4 还没做
- 客户端面板改样式需要重启 DSH（逻辑层才热重载）
